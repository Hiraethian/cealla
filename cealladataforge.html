Load an existing file

Paste the contents of a cealla-data.js file, or pick the file, to carry on editing it. This replaces everything currently loaded.

Danger

Wipes all entries in this tool. Your published file is untouched until you upload a new one.

Repository

Where the file gets committed. The branch needs GitHub Pages turned on in the repository's settings, serving from the branch root.

Access token

Use a fine-grained personal access token limited to this one repository, with Repository permissions → Contents set to read and write. Nothing else. The token is sent only to api.github.com.

Publish

Publishing replaces the whole file rather than merging into it. If you are on a different browser or machine than last time, load the live file before you edit.
